# <알아두면 쓸모있는 AI> 원고 작성 가이드

1회차 샘플 원고(2026-10-23 방송)를 분석해 정리한 규칙입니다. 매주 원고는 이 가이드를 따릅니다.

## 1. 프로그램 개요
- 대상: 50대 이상 신중년 **왕초보** 청취자. 휴대폰 중심, 글자 입력이 부담스럽고 앱 설치도 낯선 분들
- 출연: 진행자(DJ) + 민지희 강사(AI인문학 강사)
- 분량: 30분 방송 코너 원고. **본문 약 1,800~2,300자(공백 제외)**, 1회차는 약 1,970자
- 원칙: **1회 = 꿀팁 1개.** 여러 툴을 나열하지 않는다. 한 가지 기능으로 3가지 장면을 시연한다.

## 2. 고정 구성 (질문 7개)
| 순서 | 역할 | 내용 |
|---|---|---|
| 오프닝 | 진행자 | "AI를 더 쉽고 편리하게! …" 5줄 내외, 강사 소개 |
| 인사 | 강사 | `-안녕하세요! AI인문학 강사 민지희입니다.` (회차별로 한 줄 덧붙여도 됨) |
| 질문1 | 진행자 | 오늘 주제로 들어가는 생활 공감 질문 (신중년이 실제 겪는 문제) |
| 질문2 | 진행자 | 문제를 구체화 / 왜 어려운지 |
| 질문3 | 진행자 | 오늘의 해결책(기능) 소개 + **최신 소식**(언제 생겼는지, 무료/유료) |
| 질문4~6 | 진행자 | **시연 3개** (첫 번째·두 번째·세 번째). 각 시연은 `• 민지희 :` / `• AI :` 대화 예시 |
| 질문7 | 진행자 | "청취자분들이 집에서 꼭 해보셨으면 하는 활동" → **이번 주 숙제 문장 1개**(인용부호) |
| 클로징 | 진행자 | `>>>>>` 로 시작, 오늘 내용 요약 + "다음 주도 기다릴게요" |
| 마무리 | 강사 | `-네, 감사합니다.` |

- 진행자 질문은 2~4줄로 짧게 끊어 쓴다(라디오 낭독 호흡). 앞 답변에 반응하는 `(답변 +)`, `(답변+)` 표기 사용 가능
- 진행자는 청취자 입장에서 "어르신들은 ~에서 막히시거든요?" 처럼 걱정·궁금증을 대신 말한다

## 3. 강사 답변 문체
- 존댓말 구어체 "~해요 / ~거예요 / ~해 보세요". 문장은 짧게. 전문용어는 바로 풀어서
- 화면 조작은 **버튼 이름과 위치**로 설명: "대화 화면의 + 버튼을 누르면 카메라 메뉴가 나와요"
- 무료/유료 구분, 순차 적용, 사용량 제한 등 **현실적인 단서**를 반드시 한 줄 넣는다
- 시연 지문은 괄호: `(민지희 강사가 휴대폰으로 AI와 대화한다. 아래 AI 답변은 예시)`
- AI 답변 예시는 짧게, 끝에 "한 번 더 확인해 보세요" 같은 안전 문구를 자연스럽게
- 건강·돈·법률 주제는 "최종 확인은 약사·전문가·공식 사이트에서"를 꼭 넣는다
- 개인정보(주민번호, 계좌, 비밀번호)를 AI에 넣지 말라는 안내를 주제에 맞게 넣는다

## 3-1. 전달 스타일: "김덕진 소장 스타일"의 대중 IT 해설 (전 회차 공통)
제작진이 정한 방향입니다. 특정인을 흉내 내는 게 아니라 **어려운 기술을 생활 언어로 푸는 대중 해설 방식**을 따릅니다.
- **한마디 정의 먼저**: "요즘 AI, 한마디로 하면 ○○예요." 기능 설명보다 정의·비유가 먼저
- **생활 비유**: 백화점·동네 병원·비서·통역사·만능 리모컨처럼 신중년이 아는 것에 빗댄다. 한 회에 비유는 2~3개만
- **뉴스 한 줄 + 내 생활 연결**: "요즘 이런 일이 있었어요(숫자 하나)" → "그래서 우리한테 뭐가 좋으냐면요"
  숫자는 한 회에 1~2개, 반올림해서 귀에 들어오게("두 명 중 한 명꼴")
- **세 가지로 정리**: "딱 세 가지만 기억하세요." 리듬감 있는 표어로 만든다(예: 찾고·확인하고·누르고)
- **겁 먼저 풀기**: 돈 나갈까, 고장 날까, 개인정보 샐까 같은 걱정을 먼저 꺼내고 바로 안심시키고, 진짜 주의할 점은 분명하게
- **진행자와 주고받기**: 강사 답변은 짧게 끊고, 진행자가 되묻고·정리하고·감탄하며 리듬을 만든다

## 3-2. 보는 게 아니라 듣는 라디오
청취자는 화면을 볼 수 없고, 운전하거나 일하면서 듣는 경우가 많습니다.
- **모양·위치·색으로 말하기**: "오른쪽 아래 동그란 버튼", "물결 모양", "마이크 모양". 아이콘 이름이나 메뉴 경로를 길게 읽지 않는다
- **따라 하기는 3단계 이내**: 단계마다 번호를 붙여 말하고, 클로징에서 한 번 더 반복한다
- **받아 적을 필요가 없게**: 인터넷 주소, 긴 영어, 복잡한 숫자는 말하지 않는다. 앱 이름 하나와 표어 하나만 남긴다
- **시연은 소리로 그림이 그려지게**: "지금 버튼을 눌렀더니 '띵' 하고 AI가 듣기 시작했어요"처럼 지금 무슨 일이 일어나는지 말로 중계한다
- **한 문장 한 정보**: 문장 하나에 정보 하나. 괄호 설명이나 영어 약어는 피하고, 꼭 써야 하면 바로 풀어 준다
- **핵심 반복**: 오늘의 표어(curriculum 의 takeaway)를 답변 중간과 클로징에서 최소 두 번 들려준다
- **막혔을 때의 출구**: "모르면 AI에게 '이 버튼 뭐야?'라고 물어보세요", "자녀·손주에게 같이 해보자고 해 보세요"

## 4. 주제 선정 원칙
- 단순 검색이 아니라 **최신 기능**(사진·카메라, 음성, 메모리, 예약 작업/알림, 이미지 생성, 녹음 요약, 딥 리서치 등)을 활용
- **휴대폰 하나로 지금 바로** 따라 할 수 있을 것. 가능하면 무료로 되는 방법을 먼저, 유료는 "유료 쓰시는 분은 ~까지"로
- 생활 · 업무 · 가족 · 외주 서비스 의뢰 · 안전 영역을 고루. 계절·명절과 맞춘다
- 방송 주에 기능 출시 여부, 한국어 지원, 요금제를 **반드시 공식 자료로 재확인**한다

## 5. 원고 소스 형식 (`radio_ai/episodes/epNN.md`)

## 인사

## 질문1
(진행자 질문 줄들)

## 답변
(강사 답변. 한 줄 = 한 문단, 빈 줄 = 빈 문단)
> “강조할 인용 문장” (줄 앞의 > 는 강조 글자모양으로 바뀜)
• 민지희 : ...
• AI : ...

## 질문2
...
## 클로징
(첫 줄 앞에 >>>>> 가 자동으로 붙음)

(방송 원고에는 들어가지 않음. 작가·PD용: 준비물, 사전 세팅, 팩트체크 출처, 대체 시연)
